# LeetCode Java

Este repositório reúne minhas soluções para problemas do LeetCode utilizando **Java**.

O objetivo não é apenas resolver os desafios, mas desenvolver habilidades de resolução de problemas, raciocínio lógico e domínio das estruturas de dados e algoritmos mais utilizados em entrevistas técnicas e no desenvolvimento de software.

Neste repositório, priorizo compreender o problema antes de consultar uma solução. Quando necessário, estudo diferentes abordagens para entender o raciocínio por trás do algoritmo, em vez de apenas memorizar o código.

## Objetivos

- Praticar Java
- Estudar estruturas de dados
- Desenvolver raciocínio algorítmico
- Estudar diferentes abordagens para um mesmo problema
- Registrar minha evolução

## Padrão das soluções

Sempre que possível, procuro implementar mais de uma abordagem para o mesmo problema.

Por exemplo:

- Solução direta
- Solução utilizando estruturas de dados
- Solução otimizada
- Solução com menor uso de memória

Além do código, busco compreender:

- Por que a solução funciona
- Complexidade de tempo
- Complexidade de memória
- Possíveis melhorias

## Complexidade

Em cada solução procuro identificar:

- Time Complexity
- Space Complexity

Exemplo:

// Time Complexity: O(n)
// Space Complexity: O(1)
